Security AI Lab - Local Start Info

Run all commands from:
f:\Projects\security-ai-lab

FAST START

Single command:
npm run dev:up

What it does:
- starts the PostgreSQL Docker container on port 5433
- starts the HTTPS backend on port 5000 if it is not already running
- starts the HTTPS frontend on port 3000 if it is not already running

FIRST TIME SETUP

1. Install dependencies
npm install

2. Create env files if missing
Copy-Item .env.example .env
Copy-Item backend\.env.example backend\.env
Copy-Item frontend\.env.example.local frontend\.env.local

3. Leave backend\.env with:
REDIS_URL=memory://local

4. Install Ollama locally if you want live model replies
ollama pull qwen2.5-coder
ollama pull nomic-embed-text

5. If your local PostgreSQL does not have pgvector, the app still starts
RAG upload and retrieval stay disabled until pgvector is installed

MANUAL START

1. Start PostgreSQL on port 5433
docker compose up -d postgres

2. Start backend in terminal 1
npm run dev:backend

3. Start frontend in terminal 2
npm run dev:frontend

OPEN IN BROWSER

Frontend:
https://localhost:3000

Backend health:
https://localhost:5000/health

STOP

If you used the fast start command:
npm run dev:down

If you started manually:
Stop app terminals with Ctrl+C

USEFUL CHECKS

Check backend health:
curl.exe -k https://localhost:5000/health

OPTIONAL MODELS

If you want local model responses too:
docker compose up -d ollama
